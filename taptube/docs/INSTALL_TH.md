# วิธีติดตั้งและเล่น TapTube Reborn 1.6.5 (No IAP)

## 0. มีอะไรใหม่ในรุ่นนี้ (แก้เสียงไม่ดัง)

รุ่นนี้แก้ปัญหา **"เพลงไม่เล่น / ไม่ได้ยินเสียง"** โดยตรง:

1. เพลงเล่นผ่าน **MediaPlayer ของ Android** (ดึงสตรีมเสียงจาก YouTube โดยตรง) — ไม่ขึ้นกับว่า iframe ฝังได้หรือไม่
2. วิดีโอ iframe ใช้เป็นภาพอย่างเดียว (ปิดเสียง) เพื่อไม่ให้ทับกับเพลง
3. ถ้าเพลงเล่นไม่ได้ (วิดีโอส่วนตัว/ติดภูมิภาค) เกมจะเล่น **จังหวะบีตสำรอง** ให้ทันที ไม่เงียบ
4. ระหว่างเล่น กด ⏸ แล้วเลื่อน **ระดับเสียงเพลง** ได้ / หน้าต่างเตือนมีปุ่ม **"แก้เสียงไม่ดัง"**
5. ตั้งค่า › ทั่วไป มีสไลเดอร์ **เสียงเพลง** และ **เสียงวิดีโอ**

ถ้ายังไม่ดัง: เพิ่มระดับเสียง **สื่อ (Media)** ของเครื่อง ปิดโหมดห้ามรบกวนที่บล็อกเสียง แล้วกดปุ่ม "แก้เสียงไม่ดัง" ในเกม

## 2. ติดตั้ง
1. ดาวน์โหลด APK ลงมือถือ
2. เปิดไฟล์ → ถ้ามีข้อความ "ติดตั้งจากแหล่งที่ไม่รู้จัก" ให้กด **ตั้งค่า → อนุญาต** ให้แอปที่เปิดไฟล์ (Chrome/ไฟล์) แล้วกดติดตั้งอีกครั้ง
3. เปิดแอป **TapTube** จากหน้าจอหลัก

> แอปนี้ไม่ได้อยู่ใน Play Store จึงต้องอนุญาตติดตั้งจากภายนอกครั้งเดียว (ปกติของ APK)

## 3. เล่นเพลงจาก YouTube
- แท็บ **ค้นหา YouTube** → พิมพ์ชื่อเพลง/ศิลปิน หรือวางลิงก์ YouTube → แตะเพลง → **เตรียมเล่น** → **เริ่มเกม!**
- แท็บ **ยอดฮิต / แนะนำ** มีเพลงตัวอย่างให้เล่นทันที
- ถ้าเพลงนั้นเจ้าของปิดการเล่นนอก YouTube เกมจะขึ้นแถบเตือน พร้อมปุ่ม
  - **หาเวอร์ชันเสียงอื่น** → ค้นหาเวอร์ชัน audio ให้อัตโนมัติ
  - **เล่นด้วยเสียงบีตในเกม** → โน้ตยังตรงจังหวะทุกจังหวะ

## 4. ตั้งค่าที่ควรรู้
| ต้องการ | ไปที่ |
| --- | --- |
| เปลี่ยนภาษา (ไทย/EN/JA/KO) | ตั้งค่า → ทั่วไป → ภาษา |
| ความเร็วโน้ต / จำนวนเลน / โน้ตค้าง-สไลด์ | หน้าต่าง READY ก่อนเริ่มเกม |
| ปรับซิงก์โน้ต (ถ้าเสียงกับโน้ตไม่ตรง) | ปุ่มหยุดพักระหว่างเล่น → เลื่อน **ปรับซิงก์โน้ต** |
| ความสว่าง/ซูมวิดีโอพื้นหลัง | ตั้งค่า → วิดีโอ |
| ปิดเสียงเอฟเฟกต์ / สั่น | ตั้งค่า → เอฟเฟกต์ |
| สร้างชาร์ตโน้ตเอง | ปุ่มดินสอ (✎) บนการ์ดเพลง → แตะถนนเพื่อวางโน้ต |

## 5. YouTube API Key (ไม่บังคับ)
ในเกม Android การค้นหาทำงานได้โดยไม่ต้องใช้คีย์เลย ถ้าอยากให้เสถียรที่สุด:
1. เปิด https://console.cloud.google.com → สร้างโปรเจกต์
2. APIs & Services → Library → เปิด **YouTube Data API v3**
3. Credentials → Create credentials → **API key**
4. นำคีย์ไปวางที่ **ตั้งค่า → ทั่วไป → YouTube API key**

โควตาฟรี 10,000 units/วัน (ค้นหาได้ราว 100 ครั้ง/วัน)
